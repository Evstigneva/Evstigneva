### 🚀 Избранные проекты

* **🪵 Детекция досок на конвейере** 
  Система подсчёта досок разного размера на производственной линии. Реализована детекция и трекинг объектов в реальном времени. *(Стек: Python, PyTorch, OpenCV)*. Проект успешно закрыт.
* **🛥 Система компьютерного зрения для парковки хаусботов** 
  Мультикамерная система для контроля парковки яхт и хаусботов в реальном времени. *(Стек: CV, Python)*.
* **🤖 Многофункциональный Telegram-бот (GAN + YOLO)** 
  Разработка бота, объединяющего генерацию изображений и детекцию объектов. Написала **GAN-нейросеть с нуля** и обучила её на датасете **COCO**. Интегрировала **YOLO** для детекции объектов на фото и видео. Весь пайплайн упакован в Telegram-бота. *(Стек: Python, PyTorch, YOLO, OpenCV, Telegram Bot API)*.
* **🎥 Асинхронный Telegram-бот для выдачи видео по QR-коду** 
  Высоконагруженная система, обслуживающая тысячи пользователей. Асинхронный бэкенд на `asyncio` и `aiohttp` обрабатывает запросы в реальном времени, отправляет видео и ведёт подробное логирование в PostgreSQL (кто, когда и какое видео запросил). *(Стек: Python, asyncio, aiohttp, PostgreSQL)*.
* **🏆 Прогнозирование спортивных матчей** 
  ML-пайплайн на табличных данных для предсказания исходов спортивных событий. Проект в активной разработке. *(Стек: scikit-learn, Pandas, Python)*.
* **🕸 Автоматизация и парсинг данных** 
  Разработка парсеров различной сложности с использованием Playwright, Selenium и BeautifulSoup. Обход антибот-защиты, работа с прокси и извлечение структурированных данных из веб-источников.
